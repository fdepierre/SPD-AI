# SPD-AI: Software Product Development with AI in Europe

This repository gathers working documents on how AI agents change the way software products are built, managed and governed, with a European focus: sovereignty of the tool chain and regulation (AI Act, NIS2, Cyber Resilience Act, GDPR).

The documents are written in French for now.

## Status

These are working documents, generated with an AI, not scientific papers. Each important claim is labelled as a documented fact, an actor's statement, a hypothesis, a recommendation or an open question. Some figures and claims have not yet been checked against their primary sources. They're marked as such, and the main document lists them in its appendix H.

Consider these contents as a context of knowledge for your own analysis, not proofs validated.

## Contributing

Corrections, missing references and counter-arguments are welcome. Please open an issue, and give a source where you can.
